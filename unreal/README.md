# Unreal handoff

Open `Singularity.uproject` in Unreal Engine 5.4. Import the GLB files generated by `../art/blender/generate_singularity_assets.py` into `/Game/Singularity/Art`.

Create a Blueprint `BP_SharedBody` with six Chaos rigid bodies and constraints named `EyesHead`, `LeftArm`, `RightArm`, `TorsoBack`, `LeftLeg`, and `RightLeg`. Bind Enhanced Input to role-specific force vectors and grab actions. SpacetimeDB remains authoritative for role leases, inputs, fixed-step state, clocks, checkpoints, and leaderboard rows.
